Field · since 2024

No one types an IP on a factory floor

The field app finds every robot on the network by itself, then installs, updates and fixes it.

A simplified, general version of how this works. No company code, customer names or internal details.

The problem

Field engineers set up robots on networks they have never seen. Finding each robot's address by hand and following long checklists is slow and easy to get wrong.

How it works

A small discovery node runs on every robot. The field app sends one broadcast on the local network asking who is there, each robot answers directly with who it is, and the app checks it can reach the robot before opening a secure session. From there the app runs the usual field work: maps and paths, parameters, logs, software updates and network setup, with each user's permissions cached so the app works on site without internet.

What I built

  • The discovery node on the robot, and the first broadcast client in the field app.
  • Two major release updates of the field app in 2024, plus an in place upgrade path for the robot software stack.
  • In 2026: switching a robot between regions, license reset, session expiry handling, cellular router setup and tablet layouts.

Choices that mattered

  • Broadcast and reply. No setup on the network, no typing addresses.
  • Check before connecting. The app only offers robots it can actually reach.
  • Permissions cached for offline. The app works in a basement with no signal.
