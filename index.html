How I work with AI

Claude Code and Cursor, every day.

Coding agents let me ramp up fast on new or legacy code and move quickly once I know it. Speed only counts if it is safe, so every change goes through the same five steps.

  1. RulesWritten rules the agents follow: style, limits, what never to touch. I helped write my team's.
  2. PlanThe agent proposes a plan. I review the design before any code is written.
  3. BuildAgents write and refactor the code, in parallel where the work splits cleanly.
  4. CheckTests, code review, and a dry run on a real system before anything ships.
  5. LearnEvery mistake becomes a new rule, so it does not happen twice.
